# AIDevance

**RU** · [EN](#english) · Сайт / Site: [aidevance.github.io](https://aidevance.github.io/)

AIDevance разрабатывает программы командой AI-агентов (Claude, Codex, Gemini, ChatGPT) под руководством владельца:
владелец ставит требования и принимает результат, агенты пишут логику, код и тесты и проверяют работу друг друга.

## English

AIDevance builds software with a team of AI agents (Claude, Codex, Gemini, ChatGPT) led by the owner: the owner sets
the requirements and accepts the result, the agents write the logic, code and tests and check each other's work.
